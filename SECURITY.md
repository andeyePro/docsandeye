# Security

Docs&I is pre-alpha and has no release yet. If you find a security problem, please report it privately through https://contact.andeye.com/?source=docs.andeye.com&subject=Docs%26I%20security rather than in a public issue. We will acknowledge within a week. There is no bounty programme.

Scope: the `docsandeye` CLI, the Python render pipeline, the Starlight plugin and the theme packages in this repository. Guides built with Docs&I are their authors' responsibility.
