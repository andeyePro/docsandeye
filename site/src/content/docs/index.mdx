## What it is

Docs&I (`docsandeye` in code) builds assembly guides for open-source hardware. Every step shows three things side by side:

- a short, self-hosted, low-carbon video of the step;
- the full text, complete on its own, never a caption;
- drawings rendered from the CAD files, so a guide can be complete with no photography at all.

Each video declares which components are its hero and which are merely in frame. When a hero component's design changes, the guide notices at build time. The video steps back, text and fresh renders become the primary content, and a reader who still wants the older video is first shown what changed. Maintainers get the inverse view: a dashboard of which videos need reshooting, and why.

## Status

Pre-alpha. The schemas, the render pipeline, the video encode pipeline, the Starlight plugin, the CLI and this theme pack exist. `docsandeye diff` restores a stale shot's old geometry from git and the step page shows it beside the current model. There is no npm release yet.

The example guide under [/example/](/example/) is a made-up bench lamp. It exercises every part of the engine with hand-exported drawings, so it builds without CAD tools.
